# Ahamed Asri — Portfolio

A modern, interactive personal portfolio for **Ahamed Asri**, a Computer Science undergraduate working where **cybersecurity meets artificial intelligence**.

Designed as a digital space to showcase security tools, AI projects, certifications, and the path so far — with a strong focus on cinematic motion, bold typography, and a distinctive visual identity.

🔗 **Live site:** <https://ahamedasri.dev>

---

## ✨ Features

- Fully responsive, single-page portfolio layout
- Animated intro loader and full-bleed hero with a name that fits any screen
- Buttery smooth scrolling with scroll-linked animations throughout
- Pinned horizontal projects showcase with a pause before and after it slides
- Stacking journey cards that deal themselves out as you scroll
- Certifications section with 3D-tilt badges and a full-size certificate viewer
- Magnetic buttons, custom cursor, and spotlight hover cards
- All personal content kept in one data file for easy updates
- Respects reduced-motion preferences
- Fast dev/build cycle powered by Vite

---

## 🛠 Tech Stack

| Layer | Technology |
|---|---|
| UI Library | [React](https://react.dev/) — component-based UI |
| Language | JavaScript (JSX) — modern ES modules |
| Build Tool | [Vite](https://vitejs.dev/) — dev server and bundler |
| Styling | Hand-written CSS — custom properties, grid, and fluid type |
| Animation | [Framer Motion](https://motion.dev/) — scroll-linked and spring-based animation |
| Smooth Scroll | [Lenis](https://lenis.darkroom.engineering/) — smooth, inertia-based scrolling |
| Runtime | Node.js / npm — scripts, installs, builds |

## 🎨 Design Philosophy

This portfolio isn't built off a generic template — it's designed around a dark, cinematic identity that mirrors its subject: the precision of security work and the momentum of AI. Giant display type, serif italic accents, and deliberate motion carry the story, with every animation there to guide attention rather than distract from the work.
